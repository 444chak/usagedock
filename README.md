# UsageDock

A small native Windows 11 dock that shows Claude Code and Codex quota usage on the right edge
of the screen.

- C# / .NET 10 / WPF, no WebView, no Electron
- Always on top, never steals focus, never appears in the taskbar
- Sized to exactly the visible UI so it cannot block clicks anywhere else on screen

Work in progress. See the build instructions at the bottom of this file as they land.
